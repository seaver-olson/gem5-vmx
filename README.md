# The gem5 Simulator - Intel Virtual Machine Extensions (VMX) Support

This is the repository for the gem5 simulator with support for Intel Virtual Machine Extensions (VMX). This repository includes the necessary modifications to the gem5 codebase to enable VMX support, allowing users to simulate and analyze virtualized environments.

This repository is still in active development and may not be fully functional. Contributions and feedback are welcome to help improve the implementation of VMX support in gem5.

The main goal of this project to to provide a comprehensive and accurate simulation environment for researchers and developers working with virtualized systems, enabling them to explore the performance and behavior of virtual machines under various configurations and workloads.
